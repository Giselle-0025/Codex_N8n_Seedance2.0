01 / TOOLKIT

先认识创作工具

原始指南包含三类 Skill；配合 Codex 编写分镜脚本，随后在 n8n 中执行自动化流程。

SKILL / 01
▧

资源库 Skill

创作所需的资源库相关 Skill；在进入生成流程前，先确认角色及妆造等资源。

SKILL / 02
✧

导演 Skill

创作流程中的导演类 Skill，与剧本及分镜准备环节配合使用。

SKILL / 03
▤

分镜师 Skill

创作流程中的分镜类 Skill；最终将镜头信息整理为约定列名的 Excel 表格。

执行工具：Codex + Skill（撰写分镜脚本）、COSBrowser（查看资源与生成结果）、n8n（运行 WF00 / WF29 / WF39）。
02 / THE PIPELINE

从剧本到视频，五个步骤

按顺序执行工作流，在图像与视频两个环节进行人工复核；发现问题后修订素材或 Prompt，再重新生成。

01
SCRIPT INPUT

撰写分镜脚本

默认使用 Codex 的 Skill 撰写分镜脚本，按约定字段整理并准备好 Excel 文件，作为后续生成的输入。

02
ASSET CHECK

在 COSBrowser 核对资源

在运行 WF00 之前，先确认当前人物形象与妆造符合剧情要求。资源有误时，先修正，再进入发布环节。

03
WF00 / RESOURCES

发布资源文件

确认资源无误后，在 n8n 执行 WF00，完成资源文件的发布，再继续后续生成。

▧✓
04
WF29 / IMAGE

批量生成四宫格分镜图

向 WF29 输入分镜脚本 Excel，使用 GPT-Image-2 生成每集四宫格分镜图。图像保存至 COSBrowser 所连接的对象存储，逐一检查画面畸变与剧情一致性，并修订分镜图或视频 Prompt。

画面畸变检查剧情一致性检查Prompt 迭代
05
WF39 / VIDEO

批量生成分集视频

向 WF39 输入分镜脚本 Excel，使用 Seedance 2.0 生成分集视频。视频片段保存至 COSBrowser 所连接的对象存储，逐一核查画面与剧情，有问题时修订分镜图或视频 Prompt。
