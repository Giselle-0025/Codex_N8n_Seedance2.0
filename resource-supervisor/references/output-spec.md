# 输出结构与提示词模板

## 视觉圣经

用简洁字段记录：项目名、故事时代、地域、类型、核心情绪、视觉媒介、写实程度、色彩体系、主辅光、镜头倾向、主要材质、服装原则、场景原则、允许元素、禁用元素、视觉推断。

## 资产总表

每行包含：

`ID | 类别 | 标准中文名 | 变体 | 首次出现 | 关键出现 | 剧情证据 | 叙事功能 | 连续性锚点 | 优先级 | 提示词状态 | 图片状态 | 质检结果`

ID 使用 `CHR-001`、`PRP-001`、`LOC-001`。优先级使用 A（核心）、B（重要）、C（补充）。

## resource_registry.xlsx

每次分析新剧本、新增集数或修订版剧本，都输出或增量更新一份 `resource_registry.xlsx`。默认工作表名为 `resource_registry`，列名及顺序严格固定为：

`project_id | resource_id | resource_type | name | aliases | object_key | description | always_include | priority | enabled | version`

- 有旧表时：保留原工作表名、格式、既有行、编号和对象路径规则，仅追加去重后的新增资源。
- 无旧表时：按 `CHA_001`、`PRO_001`、`LOC_001` 分类别递增编号；`resource_type` 只使用 `character`、`prop`、`location`。
- 人物装造或状态图：按独立 `character` 资源行登记，`name` 使用“人物名·装造名/状态名”，并与图片一一对应。
- `aliases`：使用 `|` 分隔中文名、英文名、称呼或剧情常用指代。
- `object_key`：使用 `[项目资源前缀/]resources/characters|props|locations/资源ID.png`。旧表或用户给出前缀时原样继承；未给出时从 `resources/...` 开始。
- 默认值：`always_include=false`、`priority=10`、`enabled=true`、`version=v1`；若项目旧表使用不同的数据表达则沿用旧表。
- `description`：准确、简洁、可供后续提示词识别。人物优先复用已确认表中的短外貌概括，省略神态、身份、动作和不必要的剧情描述；物料与场景保留能区分资产的结构、材质和关键空间特征。
- 交付前检查：11 列名称与顺序完全一致，`resource_id` 唯一，资产无重复，`object_key` 与类别及图片文件名一致，工作簿能够正常打开。

## 人物装造连续性表

每个跨场人物至少一行，每个独立装造变体单独一行：

`人物 ID | 装造变体 ID | 人物名 | 装造名 | 适用集数/场次 | 剧情阶段 | 换装触发原因 | 服装层次 | 鞋履 | 配饰 | 发型与妆容 | 磨损/伤后状态 | 与基础定妆共享的身份锚点 | 剧本明示/视觉推断 | 图片状态 | 质检结果`

变体 ID 使用 `CHR-001-A`、`CHR-001-B`。A 默认为基础定妆；后续字母按剧情首次出现顺序排列。一个场次只能映射到该人物的一套主装造，除非场内明确换装。

## 通用提示词结构

按以下顺序写成一条可直接用于图像生成的完整提示词：

1. 交付类型与画幅；
2. 元素名称与一句话剧情身份；
3. 可见外观、材质、年代和使用状态；
4. 与关键场次或行动相关的剧情细节；
5. 全局创作风格；
6. 构图、机位、镜头、光线和色彩；
7. 连续性锚点；
8. 类别专属硬性要求；
9. 负面约束。

紧随提示词附上：

- 剧情依据：列出集数、场次、页码或原文附近的可定位标识。
- 视觉推断：只列剧本未明示但为出图补充的内容。
- 连续性锚点：列出跨图不得改变的 3–8 个特征。

## 人物提示词模板

```text
横向 16:9、纯白背景的影视人物设定板，推荐尺寸 1600×900。人物：[中文名]，[剧情身份与当前阶段]。[年龄感、地域特征、脸型五官、发型、肤色、体型、姿态、表情]；穿着[符合时代、身份和关键剧情的服装、鞋履、配饰、磨损或伤痕]。整体遵循[全局创作风格]，中性棚拍光，真实材质，无环境。

严格版式：左侧约 40%，只放一张放大的正面头肩细节图，完整保留头顶，脸部清晰，下边缘裁至锁骨附近，只露出少量肩部和服装领口；右侧约 60% 平均分成三个等宽区域，从左到右排列同一人物的正面全身、严格 90 度侧面全身、完全背面全身，三个人物等高、等宽、基线一致，全部从头顶到脚底完整可见。四个视图为同一个人、同一套服装、同一发型与配饰、同一身材比例。左上角仅用清晰中文标注“[中文名]”。

连续性锚点：[锚点列表]。不要环境、家具、道具堆叠、动作姿势、戏剧性透视、裁脚、遮挡、额外人物、额外肢体、重复身体、视角错误、服装变化、脸部漂移、年龄漂移、英文、拼音、说明文字、水印、logo、边框装饰。
```

若人物必须持有标志性物件，仅在右侧正面全身图中自然呈现一次；不得遮挡身体轮廓或影响另外两张全身图。

## 人物换装提示词模板

```text
使用提供的[人物名·基础定妆]作为唯一身份参考，生成横向 16:9、纯白背景的影视人物换装设定板，推荐尺寸 1600×900。人物仍为同一个[人物名]：严格保持参考图中的脸型、五官、年龄、肤色、体型、身高比例和[不允许变化的发型/伤痕]。本次装造为“[装造名]”，适用于[集数/场次与剧情阶段]，换装原因是[剧本明示或视觉推断]。

只将服装更换为[上装、下装、外套、鞋履、配饰、材质、颜色、合身程度、磨损或天气状态]；允许变化项仅为[必要发型、妆容或伤后状态，没有则写“无”]。不得改变身份、脸部、年龄、体型或肤色。

严格版式：左侧约 40%，只放一张放大的正面头肩细节图，完整保留头顶，脸部清晰，下边缘裁至锁骨附近，只露出少量肩部和服装领口；右侧约 60% 平均分成三个等宽区域，从左到右排列同一人物、同一套新装造的正面全身、严格 90 度侧面全身、完全背面全身，三个人物等高、等宽、基线一致，全部从头顶到脚底完整可见。左上角仅用清晰中文标注“[人物名]·[装造名]”。中性棚拍光、真实服装材质、无环境。

身份连续性锚点：[基础定妆共享锚点]。装造连续性锚点：[新服装轮廓、层次、材质、颜色、鞋履与配饰]。不要混入基础服装，不要改变脸型、五官、年龄、肤色、体型和身高比例，不要环境、家具、动作姿势、戏剧性透视、裁脚、遮挡、额外人物、额外肢体、重复身体、英文、拼音、说明文字、水印、logo、边框装饰。
```

提示词后必须附：适用场次、换装触发原因、剧本明示/视觉推断、身份连续性锚点、装造连续性锚点、基础定妆图片路径。

## 物料提示词模板

```text

```

## 场景提示词模板

```text
横向 16:9 的影视场景四方位四视图设定板：[场景中文名]，[该场景承载的剧情事件与情绪转折]。整个画布严格平均分为 2×2 四宫格，每一格自身均为 16:9，四格描绘同一个空间、同一时间、同一天气和同一事件状态。不得用低角度仰视、俯视或重复的总览机位替代任何一个方位。

左上总览图：[从主入口或主要叙事轴建立空间全貌、入口出口、行动路线和关键区域，作为其余三格的空间连续性母版]；右上总览图反向：[将镜头机位与左上总览图机位调换，从原镜头对侧沿同一主轴反向观察，完整交代原机位背后的空间、入口出口、行动路线和关键区域，不得做水平镜像]；左下左侧面视角：[相对左上总览图主轴向左旋转约 90 度，确认左侧墙、横向空间层次、门窗和家具关系]；右下右侧面视角：[相对左上总览图主轴向右旋转约 90 度，确认右侧墙、横向空间层次、门窗和家具关系]。

时间与状态：[昼夜、天气、季节、事件前后]；地域年代与建筑材质：[细节]；采用[全局创作风格]与[主辅光、色彩]。四格使用接近水平的观察高度和一致的空间尺度逻辑。左上总览图确定的[门窗、固定家具、道路/地面、关键陈设、物体样式、位置、朝向与摆放角度、材质、光源和剧情痕迹]必须被其余三格严格继承。连续性锚点：[3–8 个可跨角度核对的固定元素]。使用细窄中性分隔线，不要大标题、编号、说明文字、无关人物、四个不同地点、低角度仰视、俯视、重复机位、水平镜像、结构漂移、家具随机移动或旋转、错误时代科技、随机标识、不可解释光源、水印或 logo。
```

## 单图质检记录

使用：`通过 / 重试 / 有条件通过`，并逐项记录：剧情、风格、构图、连续性、文字、解剖或结构、时代、画幅。人物图额外记录：白底、16:9、左 40% 放大头肩特写且下沿接近锁骨、右 60% 正侧背全身等高等宽、中文名、四视图同一性。换装图再记录：基础定妆引用路径、跨装造身份一致性、允许变化项、禁止变化项、新装造内部一致性、适用场次覆盖。场景图额外记录：2×2 四格、单格 16:9、总览/反向总览/左侧面/右侧面顺序、反向总览机位互换且非镜像、左右侧面方向正确、无低角度仰视/俯视/重复机位、固定结构及物体样式、位置、朝向与摆放角度严格继承左上总览图、光线与事件状态一致性。
